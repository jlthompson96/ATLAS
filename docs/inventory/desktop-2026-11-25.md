**Noted, no change asked**

- Secure Boot is off. Not needed by ATLAS; the desktop holds only its WireGuard key and the LM Studio token. Owner's choice.
- Energy Efficient Ethernet is on. If WoL is unreliable in B6, this is the first NIC setting to try off.
- The Wi-Fi adapter is also wake-enabled but disconnected; the plan uses the wired NIC only.
- BIOS settings ("Wake on LAN / PCIe PME" on, ErP off) can't be read from Windows: check them in the UEFI setup before B6.
